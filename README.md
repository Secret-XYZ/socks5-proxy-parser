## ✨ Возможности

- 🌐 5 источников — GitHub-списки и ProxyScrape собираются автоматически
- 🧹 Дедупликация — каждый прокси попадает в файл один раз
- ⚡ Быстрая проверка — многопоточная TCP-проверка (200 потоков по умолчанию)
- 🔄 Автообновление — список перезаписывается каждые 15 минут
- 🛡 Безопасная запись — файл заменяется атомарно, старый список не пропадёт при сбое
- 🪶 Минимум зависимостей — нужна только библиотека requests

## 🚀 Быстрый старт

# 1. Клонируй проект или скопируй файл
git clone https://github.com/your-name/socks5-parser.git
cd socks5-parser

# 2. Установи зависимость
pip install requests

# 3. Запусти
python socks5_parser.py
После первого цикла рядом появится файл **socks5.txt**:

103.152.112.162:1080
45.77.56.114:9050
192.252.215.5:16137
...
> Формат — ip:port, по одному прокси в строке.

## ⚙️ Настройка

Все параметры находятся в начале файла socks5_parser.py:

| Параметр          | По умолчанию  | Описание                                      |
|-------------------|---------------|-----------------------------------------------|
| OUTPUT_FILE     | socks5.txt  | Имя файла, куда сохраняются прокси            |
| INTERVAL        | 15 * 60     | Интервал обновления в секундах                |
| CHECK_ALIVE     | True        | Проверять доступность порта перед сохранением |
| CHECK_TIMEOUT   | 4           | Таймаут проверки одного прокси (сек)          |
| CHECK_THREADS   | 200         | Количество потоков проверки                   |
| REQUEST_TIMEOUT | 15          | Таймаут скачивания списка из источника (сек)  |
| SOURCES         | 5 ссылок      | Список источников — можно добавлять свои      |

### ➕ Добавить свой источник

Просто допиши ссылку на текстовый список в SOURCES:

SOURCES = [
    "https://raw.githubusercontent.com/TheSpeedX/PROXY-List/master/socks5.txt",
    "https://example.com/my-socks5-list.txt",   # ← твой источник
]
Парсер сам вытащит всё, что похоже на ip:port.

## 🔍 Как это работает

1. 🌐 Скачивание — загружаются списки из всех источников
2. 🧹 Извлечение — из текста достаются адреса ip:port, дубли удаляются
3. ⚡ Проверка — многопоточная проверка открытого порта
4. 💾 Сохранение — живые прокси записываются в socks5.txt
5. ⏳ Пауза 15 минут — и всё повторяется заново

---

## ⏱ Скорость

Время проверки зависит от числа найденных прокси:

| Прокси | Примерное время |
|--------|-----------------|
| 10 000 | 3–4 минуты      |
| 20 000 | 6–7 минут       |

Пауза в 15 минут отсчитывается после завершения проверки. Чтобы ускорить цикл, увеличь CHECK_THREADS или уменьши CHECK_TIMEOUT.

## 🐳 Запуск в Docker (по желанию)

### Dockerfile

~~~dockerfile
FROM python:3.12-slim
WORKDIR /app
RUN pip install --no-cache-dir requests
COPY socks5_parser.py .
CMD ["python", "-u", "socks5_parser.py"]
~~~

### Сборка и запуск

~~~bash
docker build -t socks5-parser .
docker run -d --name socks5-parser -v $(pwd):/app --restart=unless-stopped socks5-parser
~~~

## ⚠️ Важно знать

- Проверка подтверждает только открытый порт, а не реальную работу SOCKS5-рукопожатия.
- Бесплатные прокси нестабильны: многие живут минуты, часть медленные или ненадёжные.
- Не пропускай через бесплатные прокси пароли и личные данные — их владельцы могут видеть трафик.
- Если все источники недоступны, предыдущий socks5.txt остаётся без изменений.
